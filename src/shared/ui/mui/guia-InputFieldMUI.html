InputFieldMUI

Componente de entrada basado en MUI con soporte para validación por filtro de teclado, formato de miles, estados deshabilitado y solo lectura, adornos de iconos y textos auxiliares.

Importación

import InputFieldMUI from '@/shared/ui/mui/InputFieldMUI';

Props principales

  • name: string Identificador del campo.
  • value: string Valor controlado del input.
  • label?: string Etiqueta visible.
  • smallText?: string Texto auxiliar bajo el campo.
  • onChange: (e) => void Manejador de cambios.
  • onBlur?: (e) => void Manejador de blur.
  • error?: string Mensaje de error a mostrar.
  • disabled?: boolean Deshabilita la edición.
  • readonlyMode?: boolean Muestra solo lectura.
  • placeholder?: string Texto placeholder.
  • maxlenght?: number Límite de caracteres. Si no se define y el keyfilter es numérico (int, pint, num, money, pnum), el default es 20; en el resto de casos es 2000. Si se pasa un valor explícito (p. ej. 6), se respeta. En campos numéricos se muestra automáticamente debajo del input el texto Máximo N caracteres.
  • keyfilter?: KeyFilterType Filtra lo que el usuario puede teclear.
  • formatThousands?: boolean Muestra separadores de miles manteniendo el valor sin formato.
  • startIcon?: ReactNode Icono al inicio.
  • endIcon?: ReactNode Icono al final.
  • onEndIconClick?: () => void Acción del icono final.
  • endIconTooltip?: string Tooltip para el icono final.

KeyFilterType

Valores soportados para filtrar el input:

  • int enteros con signo
  • pint enteros positivos
  • num números con signo y decimales
  • money numérico con hasta dos decimales
  • hex hexadecimal
  • alpha solo letras A–Z
  • alphanum letras y números
  • email caracteres típicos de email
  • pnum números positivos con prefijo +
  • alpha-es letras con acentos y ñ
  • RegExp expresión regular personalizada

Formato de miles

Con formatThousands el componente muestra el valor con separadores de miles, pero el onChange recibe el valor sin comas para facilitar persistencia y validación.

Integración con React Hook Form

{`import { Controller, useForm } from 'react-hook-form';

function MiFormulario() {
  const { control, formState: { errors } } = useForm({ mode: 'onChange' });

  return (
    <Controller
      name="precio"
      control={control}
      rules={{ required: 'El precio es obligatorio' }}
      render={({ field }) => (
        <InputFieldMUI
          {...field}
          label="Precio"
          smallText="Ingresa el valor en COP"
          keyfilter="money"
          formatThousands={true}
          error={errors.precio?.message as string}
        />
      )}
    />
  );
}`}

Buenas prácticas

  • Usar rules de React Hook Form para requeridos y mensajes de error.
  • Aplicar keyfilter para prevenir entradas inválidas desde el inicio.
  • Habilitar formatThousands en campos numéricos de gran magnitud.
  • Utilizar smallText para aclaraciones cortas sin saturar la UI.
  • Preferir readonlyMode cuando el campo se muestra informativo y no editable.
Nota: El valor enviado en onChange es siempre el valor sin formato cuando se usa formatThousands, lo que simplifica almacenamiento y validación.
